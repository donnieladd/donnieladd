# AGENTS.md

## Repository role

This repository implements Dontae Ladson's public GitHub profile.

It is a **public presentation surface**, not the canonical home for private company architecture, internal GTM, private repository topology, or unpublished strategic material.

## Before making changes

1. Read the current `README.md` and inspect the assets it references.
2. Preserve the approved human voice and existing visual system.
3. Treat professional identity, titles, biographies, and capability claims as governed positioning. Do not casually invent or expand them here.
4. Verify technical claims against actual evidence before publishing them.
5. If you have access to the private form. estate, consult the canonical repository authority registry before making cross-repository changes.

## This repository owns

- the deployed public GitHub profile

- profile-specific assets
- implementation of approved founder positioning on GitHub

## This repository does not own

- private estate architecture
- internal repository topology
- company GTM plans
- internal sales or revenue plans
- product runtime truth
- visual identity canon for the entire form. ecosystem

## Public-surface rules

- Do not enumerate private repositories or private estate topology.
- Do not expose customer information, secrets, internal security details, or private operating data.
- Do not describe planned work as shipped.
- Do not turn technical control work into unsupported certification claims.
- Keep founder copy human, direct, specific, and evidence-backed.

## Claim-state rules

Preserve the difference between:

- shipped/live
- built
- actively working with
- developing
- future direction

A public profile should be impressive because the work is real, not because the language is inflated.

## Routing principle

**Find the authority before changing the artifact.**

This profile renders approved public positioning. It should not become a second source of truth for the identity or internal systems it describes.
